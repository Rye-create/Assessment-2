# Assessment-2
# CP5403 Assessment 2: LLM Project

Retrieval-augmented question answering and process-parameter extraction
for laser powder bed fusion (LPBF) additive manufacturing papers.

## Data
- Paper metadata collected from OpenAlex and Europe PMC (open-access, CC BY only).
- Full texts are downloaded from Europe PMC as JATS XML (not stored in this repo).
- See `data/epmc_metadata.csv` for the list of papers.
